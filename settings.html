Help & Documentation

Bug Tracer supports multiple upload providers:

Cloudinary

  1. Create a free account at cloudinary.com
  2. Go to your Dashboard and copy your Cloud Name
  3. Go to Settings > Upload and create a new Upload Preset
  4. Set the preset to "Unsigned" for public uploads

AWS S3

  1. Create an AWS account and S3 bucket
  2. Create IAM user with S3 upload permissions
  3. Get your Access Key ID and Secret Access Key
  4. Configure CORS policy for your bucket

Generic HTTP

  1. Set up your own upload endpoint
  2. Ensure it accepts multipart/form-data
  3. Configure authentication if needed
  4. Test the endpoint with the connection test
Note: All recordings are stored locally first. Upload is optional and only used when you explicitly upload a recording.
